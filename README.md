A standalone GitHub-compatible git forge in a single Python process: git smart HTTP (clone, fetch, push), the REST v3 API, GraphQL and an MCP endpoint, all served from its own store — no git binary, no external services.

## Run it

```sh
MAKEFUN_ENV_URL=<env url> python3 main.py
```
